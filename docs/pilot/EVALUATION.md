# Evaluation items (week 4)

Collect in the PWA (`/evaluation`). No patient identifiers.

## Observer form

1. I can greet the patient and explain my role using the app. (1–5)  
2. I can ask about pain. (1–5)  
3. I can call for a Turkish nurse quickly. (1–5)  
4. Time to find a typical card: under 15 s / 15–30 s / over 30 s.  
5. I used draft speech: never / sometimes / often.  
6. Communication I could not complete this week (count, no details that identify a patient).  
7. Missing phrases (free text, situations only).  
8. I want to keep using this tool. (yes / mixed / no)

## Preceptor form

1. I trust the phrase cards for routine talk. (1–5)  
2. The tool reduced my need to interpret simple sentences. (1–5)  
3. I saw unsafe use (speech/doses/consent). (yes/no + note)  
4. Continue after the pilot? (yes / not yet / no)

## Incident log (coordinator)

Date, phrase ID or category, what went wrong, freeze (yes/no). No names.
