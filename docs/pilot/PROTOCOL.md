# 4-week ward pilot protocol

**Pilot site (fill in):** Ankara University Hospitals — unit _______________ (obstetrics or neonatology preferred).  
**Cohort PIN (change before live go-live):** `ANKARA-MZ-26`  
**Tool:** this PWA (PIN-gated, offline phrasebook). Speech is labeled draft until steering go-live for phase 2.

## Week 0

- Steering kick-off; PIN issued only to the cohort.  
- 30-minute observer onboarding (`/training` in the app).  
- 15-minute preceptor briefing (limits: no consent, no doses, no EMR paste).  
- Put up ward poster.  
- Shadow two shifts; mark starter phrases that need rewrite.

## Weeks 1–4

- Use **phrasebook first**. Speech tab only if preceptors agree it is in “draft” mode.  
- Daily: observers star useful cards; note missing phrases in evaluation notes (no patient IDs).  
- Week 2 huddle: drop or rewrite confused items.  
- Any allergy/medication event → freeze category (see KVKK doc).

## Measures (in-app `/evaluation`)

- Time to find greeting / pain / “I need a nurse”.  
- Observer confidence; preceptor confidence (1–5).  
- Count of “could not communicate” incidents (self-report).  
- Willingness to continue after week 4.

## Success (from programme plan)

- Greeting + pain + “I need a nurse” without an interpreter in most routine moments.  
- Zero medication/allergy misunderstandings attributed to the app.  
- Preceptors willing to continue.
