# Training scripts

## Observers (30 minutes)

1. This is **not** Google Translate. Use cards the hospital has reviewed.  
2. Install: open the URL → browser menu → Add to Home Screen. Works offline after first load.  
3. PIN from the coordinator. Never share in a public chat.  
4. Demo: Greeting → Pain → “I need a Turkish nurse now” → Emergency.  
5. Tap a language to **speak** it (phone speaker toward the patient).  
6. Favorites: star the ten cards you will use every shift.  
7. Forbidden: photographing records; typing patient names; using draft speech for doses, allergies, or legal consent.  
8. If you are unsure: **call the preceptor**. The red button exists for that.

## Preceptors (15 minutes)

1. Observers are **observers**; licensed staff remain responsible.  
2. The tool helps routine talk (pain, feeding, orientation). You still take consent and medicines.  
3. If a card is wrong, tell the coordinator the **phrase ID**, not the patient’s name.  
4. Draft speech (phase 2): treat on-screen text as untrusted until you confirm.  
5. Patient may refuse the tool and ask for you in Turkish.

## Install notes (Android)

Chrome → menu → Install app / Add to Home screen. Grant microphone only if speech practice is authorized for the cohort.
